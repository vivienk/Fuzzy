# Fuzzy — V2 Christmas

Send your loved ones a 3D card.

A native PICO Spatial SDK prototype with an original low-poly Christmas island. This repository is separate from the earlier HTML concept walkthrough.

## Target

- PICO OS 6 / Project Swan; ARM64.
- PICO Spatial SDK 6.1.9; Android API 35.
- This build is not confirmed compatible with PICO 4 / older PICO OS versions.

## V2 flow

1. Open Fuzzy Christmas and select **Unwrap gift**.
2. Watch the present turn and shrink as the snowy island appears.
3. Read the sample personal message.
4. Select **Light the tree** and **Turn island**.
5. Select **Keep**. A confirmed save persists the message and initial light setting on this device.
6. Close and reopen the app. Select **Open keepsake**.
7. **Wrap again** replays the greeting without deleting the saved keepsake.

This prototype uses prepared assets and a sample message. It makes no live AI requests and does not send greetings to other users. Prompt-to-world generation and real recipient delivery remain future work. The original AI-generated-world vision is retained; V2 isolates the recipient flow for evaluation.

## Build

Install JDK 21 and Android SDK platform 35 / build-tools 35.0.0. Set `JAVA_HOME` and `ANDROID_HOME`, or add `sdk.dir` to an untracked `local.properties` file.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

The debug APK is signed for sideload testing; it is not a production store release. A release signing key and release configuration should be established before final distribution.

## Install and inspect

Enable developer mode and USB debugging on the compatible PICO device, connect via USB, and accept its debugging prompt.

```sh
adb devices
adb install -r Fuzzy-V2-Christmas.apk
adb shell am start -n com.fuzzy.christmas/.platform.LaunchActivity
adb logcat -s AndroidRuntime
```

## Headset acceptance checklist

- Launch without a crash; both 3D model and text panels are visible.
- Gift unwrap completes; the note is readable at comfortable distance.
- Tree lights toggle; turn/front view works without moving the user.
- Keep reports success; force-stop/relaunch preserves the keepsake.
- Wrap again permits replay without erasing the keepsake.
- Exit/re-enter does not duplicate models or leave them behind.
- Record an under-one-minute walkthrough from the device after passing the checks.
